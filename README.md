# شركة واجهة الرمال لقطع غيار السيارات
## Wajaht Al-Remal Auto Parts Co. - Web Platform & Secure Admin Panel

تطبيق ويب رسمي متكامل، آمن وعالي الأداء تم بناؤه خصيصاً لـ **شركة واجهة الرمال لقطع غيار السيارات** بالرياض (حي الرمال الصناعية). يتكون المشروع من واجهة عرض كتالوج احترافية للعملاء بالسمة الفاتحة والشركات التقليدية (Light Theme)، بالإضافة إلى لوحة تحكم إدارية مشفرة ومتجاوبة بالكامل مع الهواتف الذكية.

---

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** 
  - HTML5 دلالي، Tailwind CSS، JavaScript Vanilla بدون أطر ثقيلة لسرعة فائقة.
  - سمة فاتحة رسمية (Light Corporate Theme) تجمع بين الكحلي الداكن للترويسة (`#0f2942`) والأحمر لأزرار الحث على الإجراء (`#dc2626`).
  - معالجة تشويه الصور على هواتف الآيفون بنسب أبعاد ثابتة (`aspect-video`, `aspect-[4/3]`, `object-cover`).
  - نظام ترجمة لحظي (i18n) ثنائي اللغة: عربي (RTL) / إنجليزي (LTR) بدون إعادة تحميل.
  - تحسينات السيو ووسوم المشاركة (Dynamic On-Page SEO & OpenGraph).
* **الخادم الخلفي (Backend):** Node.js مع Express.js مبني وفق معايير RESTful API.
* **قاعدة البيانات (Database):** محرك SQLite مفعل بوضع WAL Mode السريع مع استعلامات مجهزة بالكامل.
* **الحماية والأمان (Cybersecurity):**
  - **Parameterized Queries:** استعلامات مجهزة 100% لمنع SQL Injection.
  - **XSS Immunity:** تطهير المدخلات والمخرجات قبل الحقن في الـ DOM.
  - **Bcrypt Hashing:** تشفير كلمات المرور بجولات تمليح عالية (12 Rounds).
  - **Helmet.js & CSP:** سياسات أمان المحتوى الصارمة وإخفاء هوية الخادم.
  - **Rate Limiting:** حماية ضد هجمات القوة الغاشمة ومحددات إرسال الطلبات.
  - **Admin Easter Egg:** إخفاء أزرار الدخول المرئية وربط لوحة التحكم برابط خفي في عام "2026" في التذييل.
